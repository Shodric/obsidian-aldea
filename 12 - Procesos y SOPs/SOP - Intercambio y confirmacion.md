# SOP — Intercambio y confirmación

## Objetivo
Que un intercambio se complete de forma clara, con confirmación de entrega y registro, minimizando disputas.

## Alcance
Todas las compras de bienes y servicios dentro del circuito.

## Roles
- **Comprador**: elige, paga y confirma.
- **Vendedor**: entrega y recibe créditos.
- **Operaciones**: media si hay problema.
- **Sistema**: transfiere créditos y registra.

## Flujo

1. **Explorar** el catálogo (filtros por categoría, zona, precio).
2. **Ver** el detalle: descripción, precio, reputación, disponibilidad.
3. **Confirmar** la compra: el sistema verifica saldo y lotes.
4. **Pagar** con créditos: se seleccionan lotes (primero los que vencen antes).
5. **Recibir** un código de confirmación (6 dígitos).
6. **Coordinar** entrega por WhatsApp o en el punto acordado.
7. **Entregar** el bien o servicio.
8. **Confirmar** con el código: la transacción se cierra.
9. **Calificar** (opcional).
10. **Registrar** la obligación del comprador (si corresponde).

## Reglas

- El precio es el publicado; no se negocia en la app.
- El código es personal e intransferible.
- Sin código no hay confirmación.
- Si no hay acuerdo, se abre una disputa.
- Los créditos se transfieren al confirmar, no antes.

## Excepciones

| Caso | Acción |
|---|---|
| El comprador no tiene saldo | Ofrecer alternativa o esperar |
| El vendedor no responde | Aviso, luego disputa |
| El bien no coincide | Disputa y mediación |
| Entrega parcial | Confirmar parcial y registrar |
| Cancelación | Revertir si no se entregó |

## Disputas

1. Abrir caso con descripción y pruebas.
2. Notificar a ambas partes.
3. Mediación en 7 días.
4. Resolución del árbitro si no hay acuerdo.
5. Sanción si corresponde.

## Registro
- ID de transacción.
- Partes.
- Monto.
- Fecha y hora.
- Código.
- Estado.
- Calificación.

## Métricas
- Intercambios completados.
- Tiempo de confirmación.
- Tasa de disputas.
- Satisfacción.
